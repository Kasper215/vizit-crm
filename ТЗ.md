# Техническое задание: CRM журнала «ВИЗИТ ДОНЕЦК»

## Назначение

Учитывать заявки бизнеса на размещение, вести этапы работы и следующие контакты. Работать с одной и той же CRM в браузере и Telegram Mini App; быстро заносить материалы из рабочих чатов через бота.

## Архитектура и данные

- Модульный Node.js-монолит: HTTP API, слой заявок/хранилища, проверка Telegram-сеанса, Mini App и Telegram bridge разделены по модулям.
- Единый API и единая SQLite база для браузерной CRM, Mini App и бота. Обновления интерфейсов читают ту же запись.
- При первом старте текущие данные `data/applications.json` переносятся в `data/crm.sqlite`; исходный JSON не удаляется.
- Клиентские документы и локальные настройки не включаются в Git.
- В production Mini App передаёт Telegram `initData`, подпись и срок действия которого проверяет сервер; доступ ограничивается `TELEGRAM_ALLOWED_USER_IDS`. Бот использует отдельный `CRM_API_TOKEN`.

## Функции CRM в браузере и Mini App

- Список заявок и канбан-воронка по этапам: «Новая», «На связи», «Материалы», «В редакции», «Опубликована», «Закрыта».
- Карточка: бизнес, рубрика, контакт, телефон, почта, Instagram, источник, заметки, срок контакта, документы, исходные сообщения и история статусов.
- Поиск по контактным и организационным полям, PDF-тексту и заметкам; фильтр по этапу.
- Сводка: всего, в работе, пора связаться и опубликовано.
- CSV-экспорт текущей выборки.
- Одинаковое чтение и редактирование из обоих интерфейсов через общий API.

## Возможности бота

1. **Быстрые действия и меню:** команды поиска, сводки и контактов на сегодня; кнопка открытия Mini App. Кнопка приложения задаётся только если указана HTTPS-ссылка.
2. **Правка черновика:** перед добавлением бот показывает извлечённые данные; пользователь может исправить бизнес, рубрику, контакт, телефон или почту.
3. **Дубли:** по телефону ищутся возможные совпадения. Можно добавить файлы и заметку к найденной карточке или создать отдельную заявку.
4. **Материалы к заявке:** поиск по телефону/бизнесу, затем добавление новых документов, текста или аудиозаметки в выбранную карточку.
5. **Голосовые заметки:** оригинальное аудио прикладывается к CRM-карточке. По умолчанию транскрипции нет, аудиофайл остаётся локально. Если пользователь настроил `OPENAI_API_KEY`, аудио отправляется выбранному OpenAI аудио-транскрипционному API и текст добавляется в заметки.
6. **Напоминания:** ежедневная Telegram-сводка о контактах со сроком сегодня или просроченным, по умолчанию в 09:00 Europe/Moscow. Бот должен быть запущен постоянно.

## Импорт из рабочей группы и пересылок

- Бот слушает только `TELEGRAM_ALLOWED_CHAT_ID` и личные пересылки от разрешённых ID.
- Для группового импорта нужны права чтения сообщений; настройте бота как администратора либо отключите Privacy Mode.
- Для личного импорта пользователь отправляет боту `/id`, затем его числовой ID добавляется в `TELEGRAM_ALLOWED_USER_IDS`.
- Документы, изображения, видео и аудио скачиваются локально; PDF извлекается через `pypdf` при наличии Python-парсера.
- Новая заявка сначала появляется как проверяемый черновик. «Пропустить» удаляет связанные временные файлы.
- Сохраняются доступные автор/дата источника и ссылка на сообщение. Старые сообщения, отправленные до подключения бота, не загружаются автоматически.

## Приёмка

- Старая JSON-база после первого запуска доступна в SQLite, а исходный файл остаётся на месте.
- Новая или изменённая запись, внесённая из браузера, видна Mini App и наоборот после обновления списка.
- API отклоняет удалённые запросы без валидного Telegram `initData` или серверного токена бота.
- Черновик можно поправить, пропустить или сохранить; совпадение по телефону позволяет прикрепить материалы к существующей заявке.
- Сроки появляются в сводке и в ежедневном сообщении бота; повторы сводки за тот же день не отправляются.
- Голосовое сообщение прикрепляется в виде аудиофайла; при настроенном ключе расшифрованный текст добавляется в заметку.
- Git не содержит `.env`, SQLite и клиентских документов.

## Запуск в Windows

Установите Node.js 22.13+ и выполните из папки проекта:

```powershell
$env:PORT='4175'
npm.cmd start
```

Откройте `http://127.0.0.1:4175/` (браузерная CRM) или `http://127.0.0.1:4175/miniapp` (локальный просмотр Mini App). Вторая команда работает в отдельном окне PowerShell:

```powershell
npm.cmd run telegram
```

При первом запуске база создаётся автоматически. Если `data/applications.json` существует и SQLite ещё пуста, записи импортируются.

## Настройка Mini App для Telegram

1. Разместите приложение по публичному HTTPS-адресу.
2. Укажите полный URL Mini App в `TELEGRAM_WEBAPP_URL`, например `https://crm.example.ru/miniapp`.
3. В production установите `NODE_ENV=production`, `HOST=0.0.0.0`, список разрешённых ID, `TELEGRAM_BOT_TOKEN` и случайный `CRM_API_TOKEN`.
4. Запустите bridge; он установит Mini App кнопкой меню приватного чата.

Без HTTPS интерфейс можно просматривать локально, но Telegram не сможет запустить его из меню бота. Публикация/настройка домена не входит в локальную сборку.

## Переменные окружения

Все ключи перечислены в `.env.example`: `NODE_ENV`, `HOST`, `PORT`, `CRM_URL`, `DATABASE_PATH`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_CHAT_ID`, `TELEGRAM_ALLOWED_USER_IDS`, `TELEGRAM_TOPIC_MAP`, `TELEGRAM_WEBAPP_URL`, `CRM_API_TOKEN`, `TELEGRAM_DIGEST_TIME`, `TELEGRAM_TIMEZONE`, `OPENAI_API_KEY`, `OPENAI_TRANSCRIPTION_MODEL`.
